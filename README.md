# FreeWorks Dashboard

FreeWorks Dashboard es un MVP desarrollado en Angular para gestionar proyectos de freelancers y clientes.

## Funcionalidades

- Listado de proyectos
- Estados de proyectos
- Dashboard visual
- Filtros por cliente, estado y prioridad
- Buscador de proyectos y entregables
- Comentarios de clientes
- Cambio manual de estado
- Notificaciones de entregas atrasadas
- Agregar entregables con fecha y archivo simulado

---

# Tecnologías utilizadas

- Angular
- TypeScript
- HTML
- CSS
- Git y GitHub
- Docker

---

# Ejecutar localmente

## Instalar dependencias

```bash
npm install
```

## Ejecutar proyecto

```bash
ng serve
```

Abrir en navegador:

```txt
http://localhost:4200
```

---

# Ejecutar con Docker

## Construir imagen

```bash
docker build -t freeworks-dashboard .
```

## Ejecutar contenedor

```bash
docker run -p 4200:80 freeworks-dashboard
```
